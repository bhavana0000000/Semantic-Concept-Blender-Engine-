The Semantic Concept Blender Engine is a FastAPI backend that uses natural language processing and transformer-based embeddings to merge two distinct concepts into a single synthesized idea. Instead of just blending keywords, it analyzes the underlying structure of both subjects to find semantic parallels and map them into a unified hybrid model.

Features
Wikipedia Integration: Automatically fetches background text for input concepts.

Transformer Embeddings: Uses SentenceTransformers to convert text into high-dimensional vectors.

Semantic Alignment: Employs cosine similarity to map and match parallel ideas between the concepts.

FastAPI Architecture: A scalable backend with structured data validation and error handling.
